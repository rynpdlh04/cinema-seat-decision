DECISION SUPPORT SYSTEM

Pilih Kursi Bioskop dengan Lebih Cerdas

CinemaSeat membantu pengguna menemukan kelompok kursi yang berdekatan berdasarkan jumlah penonton, anggaran, ketersediaan kursi, dan preferensi baris.

Mulai Simulasi

Bagaimana Sistem Bekerja?

01. Masukkan Data

Tentukan jumlah penonton, anggaran, dan baris kursi pilihan.

02. Evaluasi Aturan

Sistem memeriksa ketersediaan, anggaran, dan kebutuhan kursi berdekatan.

03. Lihat Rekomendasi

Sistem menampilkan pilihan utama, alternatif, dan alasan keputusan.

Tujuan Proyek

Proyek ini menerapkan struktur HTML, styling CSS, pengolahan dataset menggunakan array JavaScript, percabangan, perulangan, fungsi, serta sistem pendukung keputusan berbasis aturan.
